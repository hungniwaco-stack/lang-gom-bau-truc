# Làng Gốm Bàu Trúc

Website giới thiệu Làng Gốm Bàu Trúc (Bau Truc Pottery Village) — di sản văn hóa phi vật thể UNESCO, song ngữ Việt/Anh.

- **Live:** https://vanhoacham.hungniwaco.com
- **Live (Vercel):** https://lang-gom-bau-truc.vercel.app

## Deploy

Static site, auto-deploy qua Vercel khi push lên `master`:

```bash
git add . && git commit -m "..." && git push
```
